How a GSTIN is built

CharactersMeaning
1–2State code, for example 27 for Maharashtra or 07 for Delhi
3–12PAN of the business or proprietor
13Registration number under that PAN in the state (1 for the first)
14"Z" by default for regular taxpayers
15Check digit calculated from the first 14 characters

The check digit catches most single-character typing mistakes. If it does not match, the number has almost certainly been copied wrongly.

Format check versus live status

This tool checks structure only, and runs entirely in your browser. A correctly formed GSTIN can still be cancelled or suspended. Before a large B2B sale, search the number on the official GST portal to confirm the legal name and that the registration is active.

Questions

Why does a GSTIN start with a number like 27 or 09?

The first two digits are the state code under GST. 27 is Maharashtra, 09 is Uttar Pradesh, 29 is Karnataka and 33 is Tamil Nadu.

Can one PAN have more than one GSTIN?

Yes. A business needs a separate GSTIN in each state where it is registered, and can have more than one registration in a state, which is shown by the 13th character.

What does the fourth letter of the PAN mean?

It shows the type of holder: P for an individual, C for a company, F for a firm, H for an HUF, T for a trust, and so on. The checker shows this for you.
